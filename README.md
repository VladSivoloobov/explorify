## 🔥 Почему Explorify?

| Возможность | Описание |
|-------------|----------|
| 🎨 **Темы через CSS** | Полный контроль над внешним видом — как в веб-разработке. Меняй цвета, анимации, отступы без перекомпиляции. |
| 🐍 **Модули на Python** | Добавляй новую функциональность скриптами. Интеграции, хуки, команды — всё через простой API. |
| 🔧 **Расширяй что угодно** | Панели, виджеты, контекстные меню, горячие клавиши — архитектура открыта для изменений. |
| ⚡ **Горячая перезагрузка** | Изменил CSS или модуль? Применится мгновенно, без перезапуска приложения. |
| 🧭 **Кроссплатформенность** | Windows, Linux, macOS — одна кодовая база, нативный вид везде. |

## 🎨 Темы через CSS

Пиши стили как для веба:

```css
/* ~/.explorify/themes/dark-purple.css */
window {
    background: linear-gradient(135deg, #1a1a2e, #16213e);
    color: #eee;
}

.file-item {
    padding: 10px;
    border-radius: 8px;
    transition: background 0.2s ease;
}

.file-item:hover {
    background: rgba(255, 255, 255, 0.1);
}

.file-item:selected {
    background: #0078d4;
    color: white;
}

/* Анимации? Да! */
@keyframes pulse {
    from { opacity: 1; }
    to { opacity: 0.7; }
}

.loading {
    animation: pulse 1s infinite alternate;
}
```

✅ Меняй цвета, шрифты, тени, градиенты  
✅ Добавляй анимации и переходы  
✅ Горячая перезагрузка — видишь изменения сразу  
✅ Делись темами через Git или как отдельные пакеты

## 🐍 Модули на Python

Расширяй функциональность без перекомпиляции C++:

```python
# modules/git_status.py
from explorify import Module, FileType, Event

class GitStatus(Module):
    """Показывает статус файлов Git в проводнике"""
    
    def on_init(self):
        self.register_file_decorator(self.get_git_badge)
    
    def get_git_badge(self, path: str) -> str | None:
        if self.is_git_modified(path):
            return "🟡"  # Бейдж для изменённых файлов
        return None
    
    def register_commands(self) -> dict:
        return {
            "git-commit": self.quick_commit,
            "git-diff": self.show_diff,
        }
```

✅ Пиши плагины на знакомом языке  
✅ Доступ к событиям: выбор файла, открытие, контекстное меню  
✅ Регистрируй команды, виджеты, декораторы файлов  
✅ Устанавливай модули локально или через pip (в будущем)

## 🏗️ Архитектура

Проект следует принципам Clean Architecture для максимальной расширяемости:

```
explorify/
├── core/                   # Ядро: стабильный API для модулей
│   ├── events/            # Система событий
│   ├── plugin_api/        # Интерфейсы для Python-модулей
│   └── fs/                # Абстракция файловой системы
├── presentation/          # UI-слой
│   ├── widgets/           # Кастомные виджеты GTK4
│   ├── themes/            # Предустановленные темы
│   └── css/               # Базовые стили
├── plugins/               # Система плагинов
│   ├── loader/            # Загрузчик Python-модулей
│   ├── sandbox/           # Безопасное выполнение кода
│   └── registry/          # Реестр установленных модулей
├── infrastructure/        # Внешние зависимости
│   ├── python/            # Встраиваемый интерпретатор
│   └── platform/          # Платформенные адаптеры
└── examples/              # Примеры тем и плагинов
```

## 🚀 Быстрый старт

### 🔧 Требования

- **CMake** 3.20+
- **C++20** совместимый компилятор (MSVC 2022, GCC 11+, Clang 14+)
- **GTK4** + **gtkmm-4.0**
- **Python 3.8+** (для системы модулей)
- **vcpkg** (рекомендуется для зависимостей)

### 📦 Сборка

```bash
# Клонируем репозиторий
git clone https://github.com/VladSivoloobov/explorify.git
cd explorify

# Устанавливаем зависимости
vcpkg install

# Создаём и настраиваем сборку
cmake --preset x64-debug

# Собираем
cmake --build out/build/x64-debug --config Debug
```

> 💡 **Совет**: Открой папку проекта в **Visual Studio 2022** — CMake подхватится автоматически, и ты получишь удобную IDE для разработки.

### ▶️ Запуск

```bash
# Обычный запуск
./out/build/x64-debug/explorify.exe

# С кастомной темой
./explorify --theme ~/.explorify/themes/my-theme.css

# С загрузкой модулей из папки
./explorify --plugins ./my-plugins

# Режим разработки (горячая перезагрузка)
./explorify --dev --watch
```
